# 月声尽，心灯明 —— 激昂金狮子 / 煌黑龙 战斗BGM替换 MOD v2（满响度·去前奏）

## 一、成品

| 文件 | 说明 |
|---|---|
| `月声尽_黄金奖杯_煌黑龙_BGM_v2_满响度.zip` | **MOD 本体**，根目录已是 `nativePC/sound/wwise/Windows/` |
| `打包/试听_v2_满响度去前奏.mp3` | 试听，**就是游戏里会响的那一版** |

替换对象：

| npck | 怪物 | 槽位 | 规格 |
|---|---|---|---|
| `bgm_slugger_ingame_11_00.npck` | 激昂金狮子（「你是黄金奖杯」斗技场） | 9 槽全覆盖 | 7×4ch + 2×2ch（e02/e08 原版就是 2ch） |
| `bgm_slugger_ingame_14_00.npck` | 煌黑龙 | 11 槽全覆盖 | 11×4ch |

## 二、响度（用户最常反馈的点，主动写明）

| 对象 | Integrated | True Peak |
|---|---|---|
| 盒子里旧 mod「雨爱」 | −3.8 LUFS（4ch） | +3.2 dBTP（在削波） |
| 原版金狮子 BGM | −18.2 LUFS | −0.7 dBTP |
| **本 mod v2** | **−4.1 LUFS（4ch）/ −8.0（2ch）** | +0.5 / +0.9 dBTP（不削波） |

响度已与雨爱 mod 齐平（差 0.3 dB），但没硬削波。

## 三、安装

1. **先禁用/删除**旧的冲突 mod（同改一个 npck 的，如「雨爱」）——谁后启用谁生效。
2. 导入 zip → **点「启用」**（不点不会部署到游戏）。
3. 手动装：把 zip 里的 `nativePC` 整个拖进游戏根目录覆盖。
4. 循环：wem 自带全曲循环区间，无需额外处理。

## 四、验证记录

- `verify_npck.py`：两个 npck 全部 `RESULT: ALL OK`（条目数/媒体 ID/RIFF/媒体区连续性/文件尾）。
- 逐槽声道与原版一致（11_00 的 e02/e08 = 2ch）。
- 回读解码：48kHz / 239.356s，响度 −8.0 / −4.1 LUFS 与设计一致。
- 体积：71.4MB / 100.3MB（原版 122MB / 174MB，Vorbis High 产物反而更小）。

## 五、还原

禁用或删除本 mod 即恢复原版 BGM（原版文件在游戏 chunk 包内，不受影响）。
