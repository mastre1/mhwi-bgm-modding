# 交付 zip 结构（真实交付件实测）

两次实做交付的 zip 结构完全一致，**zip 根目录直接是 `nativePC/`**（不是把 nativePC 套在子文件夹里）：

```
月声尽_黄金奖杯_煌黑龙_BGM_v2.zip        ← zip 文件名随意（中文OK）
└─ nativePC/
   └─ sound/
      └─ wwise/
         └─ Windows/
            ├─ bgm_slugger_ingame_11_00.npck    ← 金狮子（71.4MB）
            └─ bgm_slugger_ingame_14_00.npck    ← 煌黑龙（100.3MB）
```

单怪交付时只有一个 npck：

```
煌黑龙BGM替换雨爱.zip                    ← 117.9MB
└─ nativePC/
   └─ sound/
      └─ wwise/
         └─ Windows/
            └─ bgm_slugger_ingame_14_00.npck
```

## 要点

1. **zip 根 = `nativePC/`**。MOD 管理器（狩技MOD盒子）按此约定识别覆盖路径；info.xml 由盒子自动生成，不用自己写。
2. **npck 文件名必须与原版完全一致**（如 `bgm_slugger_ingame_14_00.npck`）——引擎按这个路径加载，覆盖式生效。
3. 打包用 Python `zipfile`（`scripts/A8_打包.py`）：
   - 中文路径下 tar / PowerShell Compress-Archive 容易出岔子，zipfile 稳；
   - `ZIP_DEFLATED` + compresslevel 6 即可（wem 已是压缩格式，zip 再压收益小）。
4. **同时交付一份 `试听_*.mp3`**（成品 stereo wav 转 192k mp3，就是游戏里会响的那一版），让用户装之前先听。
5. 交付 zip 旁附一份安装说明（模板见 `模板_安装说明.md`，实测范例见 `安装说明_范例.md`）。

## 狩技MOD盒子安装行为（易踩）

- 导入 zip → **必须点「启用」**：enable=false 时文件**不会**部署到游戏 `nativePC\sound\wwise\Windows\`。
- 两个 mod 改同一个 npck 时，**谁后启用谁生效**；交付说明里要提醒用户先禁用冲突 mod。
- 验证是否真的部署了：看游戏目录 `nativePC\sound\wwise\Windows\<npck名>` 的文件时间戳。
- 手动安装 = 把 zip 里的 `nativePC` 整个拖进游戏根目录覆盖。

## 还原

用户想还原原版 BGM：禁用 mod 即可（盒子部署是复制覆盖，原版件在游戏的 chunk 包里不受影响）。
制作者侧留一份原版 npck 参照件（只读！），没了用 `scripts/chunk_extract.py` 重新提取。
