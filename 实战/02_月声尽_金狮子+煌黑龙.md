## 课 1：源音频体检真不是走形式

 FLAC 源两种病灶并发：
- **截断**：STREAMINFO 写 4:14.59，实际帧只到 158s；解码器 2:38 处 `invalid residual` 整段退出；
- **坏帧**：#6889/#6890 CRC 错（≈147.0s，合计 42ms）。

判定链：`A0` 初诊 → `A3` 帧扫描 → `A4` 帧级 CRC（得坏帧号与字节区间）→ `A5` 帧头块大小累计采样数
（真实时长 157.87s；★ 字节÷码率法会估成 232s，错 75 秒）。
修复：`A6` 按帧边界切 A/B 段（FLAC 帧间独立）→ 各自重写只含 STREAMINFO 的 FLAC（总采样数改成段真实值）
→ ffmpeg 分别解码 → **40ms 交叉淡化**拼接（正好盖住剔除的 42ms）→ 末尾截断帧丢弃。
接缝样本跳变 0.0045（全曲中位 0.02），无可闻爆音。

后续 v2 改用完整 320k mp3 源（`ffmpeg -f null -` 零报错 + ASR 歌词完整验证），FLAC 弃用。

## 课 2：响度——先问对标，再动增益

v1 按原版金狮子（−18.2 LUFS）对齐到 −18.4，**用户反馈"有点小"**。
量了用户盒子里旧 mod（雨爱）才发现他的听感基准是 **−3.8 LUFS（4ch）**。
v2 改对标旧 mod：源母带 −7.2 LUFS + 2dB 推进 + `alimiter` −1.5dBFS → **−4.1 LUFS（4ch）**，与旧 mod 差 0.3dB 且不削波。

数据留档（复用价值）：
- 4ch 包的 LUFS 比同一份 2ch 高 ~4dB（v2 实测 −4.1/−8.0）——**量哪个口径的包就用哪个口径的音频量**；
- 源已是 −8 母带时 +2/+2.6/+3.2dB 实测只换 0.2 LUFS（全被 limiter 吃）；acompressor 反而让 LUFS 掉 2~6dB。

## 课 3：裁前奏用 ASR 时间戳，不靠听不靠波形

ASR 出第一句「月光会不会记得今夜」起点 **15.470s** → 裁切点 **15.25s**（提前 0.22s 留口风），
淡入 0.15s 在第一个字前结束 → 进战斗第一声就是人声。曲尾淡出 1.5s 防循环硬切。
